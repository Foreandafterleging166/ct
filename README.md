## 🎯 About this application

You use the internet every day. Sometimes, websites load slowly or refuse to open. This happens when your computer struggles to find the quickest path to a server. ct solves this problem for you.

## ⚙️ Using the software

Once the application opens, you see a menu with clear options. 

* **DNS Check:** Press the button labeled "Scan DNS Servers." The tool sends requests to various servers to measure response times. It highlights the fastest server for your region. 
* **Proxy Configuration:** If you need a proxy, press "Check Proxies." The app tests lists of SOCKS4, SOCKS5, and HTTP proxies. It filters out broken links and tests the speed of valid ones.
* **Apply Settings:** Select your chosen server or proxy from the list. Click "Apply" to save these settings to your network adapter. The tool creates a backup of your old settings. You can revert to your original connection at any time by clicking "Reset."

## 📈 Improving your network performance

You might wonder why changing your DNS settings matters. Your computer requests an IP address every time you type a web address. A slow DNS server adds a delay to every single link you click. By switching to a faster resolver, you reduce the time your browser waits before it starts loading a page.

Proxies serve a different purpose. They act as a middleman for your traffic. This helps if you face connectivity issues with specific regions or need to manage your connection path for specific tasks. The proxy checker inside this tool identifies which ones actually work, saving you from trial and error.
